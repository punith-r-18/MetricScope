GOOD TO KNOW

Why do numbers differ?

What is the difference between LOC and NCLOC?

LOC is often used as a general term for lines of code. NCLOC means non-comment lines of code. Tools can apply different rules when counting blank lines, comments and source code.

Why can cloc report more files than SonarQube?

cloc may count files such as documentation, JSON and text files that SonarQube does not analyze as supported source code for the selected project.

What is cyclomatic complexity?

Cyclomatic complexity estimates the number of independent paths through a function or program. SonarQube and Lizard may use different counting rules.

Should all three tools return identical results?

No. Each tool has its own language support and metric definitions. Small differences are expected and do not automatically indicate an error.
